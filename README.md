# 🏥 Diabetes Diagnostic Hub

A high-performance diagnostic tool designed to predict diabetes risk using advanced Gradient Boosting models. This project bridges the gap between machine learning and healthcare diagnostics with a clean, user-friendly interface.

---

## 🚀 Key Features
- 🔹 **Gradient Boosting Accuracy**: Leverages state-of-the-art ensemble learning for reliable risk assessment.
- 🔹 **Interactive Dashboard**: Direct parameter control for medical indicators like Glucose, Blood Pressure, and BMI.
- 🔹 **Instant Insights**: Real-time evaluation of risk factors with visual feedback.
- 🔹 **Serialized Performance**: Fast loading using Joblib for minimal latency.

## 🩺 Technical Stack
- **Modeling**: Scikit-Learn (Gradient Boosting Classifier)
- **Interface**: Streamlit (Premium UI)
- **Deployment**: Live Streamlit App
- **Optimization**: Feature Scaling & Regularization

## 🛠️ Usage
1. Clone:
   ```bash
   git clone https://github.com/Pravin292/diabetes-gradient-boosting-streamlit.git
   ```
2. Launch:
   ```bash
   streamlit run app.py
   ```
